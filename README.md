# Rule-Based AI Chatbot

## Project 1 - Internship

### Objective
The objective of this project is to create a simple rule-based AI chatbot that responds to predefined user inputs.

### Features
- Handles common greetings such as `hello`, `hi`, and `hey`
- Responds to predefined questions
- Uses `if-elif-else` decision-making logic
- Runs in a continuous conversation loop
- Supports exit commands: `bye`, `exit`, and `quit`
- Uses only basic Python features, so no external libraries are required

### Technologies Used
- Python 3
- Conditional statements (`if`, `elif`, `else`)
- Functions
- `while` loop
- String handling

### Project Structure
```text
rule-based-ai-chatbot/

```

### How to Run

1. Install Python 3 on your computer.
2. Open a terminal in the project folder.
3. Run:

```bash
python chatbot.py
```

### Example Conversation

```text
===================================
       Rule-Based AI Chatbot
===================================
Type 'bye', 'exit', or 'quit' to stop the chatbot.

You: hello
Bot: Hello! How can I help you?

You: what is your name
Bot: I am a Rule-Based AI Chatbot.

You: how are you
Bot: I'm doing great! Thanks for asking.

You: bye
Bot: Goodbye! Have a great day!
```
